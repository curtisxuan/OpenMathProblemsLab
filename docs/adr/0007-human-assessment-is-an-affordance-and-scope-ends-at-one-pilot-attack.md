# Human assessment is an affordance, and scope ends at one Pilot Attack

The project allows a human to assess a Conjecture — a Verdict is recorded against the same Axes as an Assessment — but nobody is expected to review every Conjecture produced. This is a schema affordance, not a workflow, so we build no review tooling: a generated Digest and a Verdict file, no sortable HTML and no terminal triage tool.

Scope ends at the Digest plus one timeboxed manual Pilot Attack on the top-ranked Conjecture. We are not building a search-and-verify harness.

## Consequences

Because Verdicts will not accumulate, the seeded Calibration Case set carries the entire calibration load rather than being a supplement to human agreement data.

The Pilot Attack exists to stop us shipping a well-engineered funnel that points nowhere. Its outcome — which Axes held up, where the Frontier estimate was wrong — is written back as a Calibration Case. An attack that is run but not recorded teaches us something for a week and then evaporates.
